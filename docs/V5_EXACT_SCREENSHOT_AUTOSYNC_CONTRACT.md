## Desired unattended behavior after a one-time connection
- Editor: existing VS Code presence extension remembers its securely paired source, discovers approved repos from local Git origin and reports only real focused edits, expiring after about 120 seconds. No per-session project selection. Other editors need their own authenticated bridge.
- GitHub: central verified GitHub App/webhook checks signatures, delivery IDs, event types and scope; synchronizes approved PR/push/release/check events without manual workflow runs. New repositories are discovered privately before owner opt-in for publication. A commit is history, not current editor activity.
- CI and Cloudflare: verified workflow/build/test outcomes; deployment status only from actual serving version and production verification. Separate deployment success from branch/build success.
- Spotify: existing encrypted D1 OAuth PKCE source, renewable tokens and owner sharing. Display approved actual track/title/artwork/progress via official API, or quiet/private/unavailable. Current implementation caches for about 60 seconds, so near-live is more accurate than instant.
- Threads: one Meta app with Threads API use case, OAuth and server-side token refresh. Read only authorized owner's own posts with threads_basic, approved engagement insights via threads_manage_insights. Project into a first-party cache with timestamps and original permalinks; keep text/likes/replies/reposts genuine; no scraping, fake feeds or private reply exposure. Permission approvals and real app installation are required.
- GPT: owner records profile / Work-Codex data occasionally through existing private batch recorder. Public dashboard always displays last approved values with provenance and capture dates. No claimed direct live GPT lifetime-usage feed.
- AI Work/Codex: ONLY participating authenticated DevonStation/agent-runner root tasks can report live states. There is no verified provider-wide feed for arbitrary ChatGPT conversations; never imply that typing in this chat automatically reaches the website.
- Semantic atlas: graph entity/relation/change records with stable IDs, versioned history and explicit publication approval. A source-qualified live event can illuminate an actual edge but cannot create a durable feature/node without a reviewed milestone. Dormant graph remains visually rich without fake activity.

## Security and truth
Public render requires global permission, specific source consent, approved project and fresh source evidence, with Stop All / revocation / private mode / expiry fencing. Keep private wiki, client/health/family records, prompts, tokens, DB payloads and unapproved repos outside the public projection. Every metric has source/scope/captured-at; historical values never acquire new timestamps solely from site polling.
