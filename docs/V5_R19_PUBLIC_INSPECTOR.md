# Living Mind V5 — R19 curated contextual inspector

**Status:** Draft review-only implementation, stacked on R18 PR #73; no main merge, provider grant, database migration, production deploy or private Knowledge import.

## Purpose

The approved 02-signal-field-primary.png and 06-signal-field-inspector-alternate.png present a substantial right-hand contextual inspector. R17/R18 had a selectable native index but no useful editorial detail in the right panel beyond an evidence caveat. R19 adds a source-grounded, progressively enhanced project/section profile using the **existing curated public portfolio** in src/content.mjs.

## Evidence and identity boundaries

- Exactly eight approved atlas roots. Seven match explicitly allowlisted project slugs in the existing public editorial catalog. The eighth, **Knowledge**, is a public section description only, not permission to query the private Knowledge wiki.
- Every project profile uses the already-published editorial title, label, status, summary and boundary. The status is labeled **CURATED PORTFOLIO STATUS · NOT LIVE TELEMETRY**, so neither public project descriptions nor GitHub links imply an active editor, deployment or source integration.
- External links are emitted only for exact, explicit public destinations: Mizvo, Rhen, Merit, Vesper, Squelch GitHub repositories or https://anevum.com. DevonStation has no external public repo link; Knowledge uses only its gated public V5 section.
- No inferred relationships, feature counts, 3D child structures, simulated activity, private client/family data, source code paths or credentials enter the profile.
- A forged, duplicated or missing root identity fails closed; all dynamic inspector text is escaped in server-rendered HTML. The browser uses static authored template content, never network/provider payloads or unsafe HTML.

## Interaction

- Native details disclosure remains a complete keyboard/no-JS way to read a public project summary and follow its public link.
- Optional JavaScript copies the matching **pre-rendered** approved profile into a contextual spotlight when the user opens a native project disclosure, chooses a left-sidebar directory entry or picks a node in the Three.js field.
- Existing R18 search/layers can hide nodes; an active spotlight is cleared when its selected root becomes hidden.
- WebGL failure does not disable search or native project inspection. No storage, browser fetch, new packages, provider accounts or long-lived source observers are introduced.
- Responsive and forced-color styling, readable headings and accessible focus/controls are preserved. The locked homepage and public V4 renderer are untouched.

## Acceptance

Require exact-head TypeScript/build, full Node suite, Git-history scanning, isolated Worker and D1 tests, Chromium/WebKit WCAG and responsive browser acceptance with native, sidebar and no-JS selections, explicit rejection of private/forged identities, screenshot artifact review and source-fenced preview. Do not infer physical iPhone/GPU performance from browser emulation.
